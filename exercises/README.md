# SQL Exercises

Run the relevant lesson first, then complete the files in this directory. The solution files are provided for self-review; attempt each task before opening them.

- **Beginner:** filtering, sorting, aggregates, and simple joins.
- **Intermediate:** multi-table joins, CTEs, grouping, and window functions.
- **Advanced:** revenue analytics, inventory, recursive CTEs, and query tuning.

Use the fictional seed data. Some tasks return empty results on a small seed dataset; the query itself should still be correct.
